# TickUp - SuperApp
---
Ce projet Flutter est une **une application Flutter moderne permettant la vente, la gestion, et le contrôle de tickets pour événement**.  
Elle offre une expérience fluide aux utilisateurs comme aux administrateurs, avec une interface intuitive et sécurisée.
---



## 🛠️ Prérequis techniques

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (>= 3.x)
- Dart SDK (inclus avec Flutter)
- Android Studio ou VS Code
- Un émulateur ou un appareil physique (Android/iOS)

---

## .🚀 Stack complet du projet
   - Framework : Flutter 3.x
   - Langage
   - Architecture : MVVM (Model – View – ViewModel)
   - State Management : Provider
   - UI Design : 
        - Typographies : Montserrat
   - Packages principaux : 
        - firebase_auth
        - cloud_firestore
        - google_sign_in
        - flutter_barcode_scanner
        - intl
        - http
