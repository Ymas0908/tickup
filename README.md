# TickUp - SuperApp
---
Tickup est une application mobile développée avec Flutter permettant la vente, la gestion et le contrôle de tickets pour des événements.
L'application offre une expérience fluide, moderne et sécurisée aussi bien pour les participants que pour les organisateurs d'événements.
---



## 🛠️ Prérequis techniques

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (>= 3.x)
- Dart SDK (inclus avec Flutter)
- Android Studio ou VS Code
- Un émulateur ou un appareil physique (Android/iOS)

---

## . Stack complet du projet
   - Framework : Flutter 3.x
   - Langage
   - Architecture : MVVM (Model – View – ViewModel)
   - State Management : Provider
   - UI Design : 
        - Typographies : Montserrat
   - Packages principaux : 
        - intl
        - connectivity_plus
        - dio
        - provider
        - logger


##  Fonctionnalités
   - Vente de billets en ligne
   - Consultation des événements
   - Achat sécurisé de tickets
   - Gestion du profil utilisateur
   - Historique des achats
   - Notifications liées aux événements

## ⚙️ Architecture
    L'application communique avec plusieurs services backend :
       - Tickup-Subs : Gestion des utilisateurs et de l'authentification.
       - Tickup-Notify : Gestion de l'envoi des emails.
